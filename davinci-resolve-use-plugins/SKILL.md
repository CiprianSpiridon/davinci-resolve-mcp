# Use plugins, effects & template packs (DaVinci Resolve)

Three different things Resolve calls "plugins/effects" reach the timeline three different ways.
Pick the right lane — mixing them up is the #1 source of "nothing happened":

| You want… | It is a… | How to apply (scriptable?) |
|---|---|---|
| Blur / glow / vignette / film look / light rays / sharpen … | **ResolveFX (OFX)** effect on a clip | ✅ `apply_ofx_to_clip(regid)` |
| Intro / title / lower-third / chapter card / subscribe / callout | **Fusion Title/Generator template** (incl. MotionVFX) | ✅ `insert_template_by_name(kind="fusion_title", name=…)` at the playhead |
| A stylized transition between two clips (MotionVFX etc.) | **Fusion Transition template** | ❌ **GUI only** — no `InsertTransition` API. Only the *default* transition is scriptable (`add_default_transition_at_cut`, a Cmd+T keystroke) |
| A MotionVFX "Effect" (Edit-page effect template) | **Fusion Effect template** | ❌ GUI only. Use a ResolveFX equivalent via `apply_ofx_to_clip` if one exists |

This is a focused composition over the base **`davinci-resolve`** MCP skill.

## Requirements
- DaVinci Resolve **Studio**, running, project + timeline open, External scripting = Local.
- Base `davinci-resolve` MCP server configured.

## 1 — Discover what's installed
**Prefer the pre-built TOC.** If `davinci-plugins.json` / `davinci-plugins.md` exists in the
project (generated by the **`davinci-resolve-generate-plugin-list`** skill), read it first — it
has every exact insert name, regid, and category already, is stable regardless of the running
server build, and avoids re-scanning. `CLAUDE.md`'s auto summary points to it. Only fall back to
the live scanners below if the manifest is missing or stale (after installing new packs → re-run
the generator).

- **ResolveFX / OFX effects** (built-in on Studio; ~105): `get_resolvefx_registry()` →
  each entry has `name`, `wireId`, and `regid` (`ofx.` + wireId). No Resolve needed.
- **Third-party OFX bundles** (FxFactory/Boris, `*.ofx.bundle` in `/Library/OFX/Plugins`):
  `enumerate_ofx()`.
- **Fusion template packs** (titles/generators/transitions/effects, incl. `.drfx` packs like
  MotionVFX): `enumerate_templates(scope="user")`. Each row: `name`/`insert_name`, `category`
  (Titles/Transitions/Effects/Generators), `insertable` (true only for Titles/Generators),
  `pack` (source `.drfx`), `path`. Filter to `insertable && category=="Titles"` for cards.
  > A `.drfx` is a ZIP holding **dozens** of templates. `enumerate_templates` expands it (needs
  > the server build with the `.drfx`-expansion fix). If it returns one uncategorized row per
  > `.drfx`, the server is old — restart it, or read names from the pack directly (see recipe 4).

## 2 — Apply a ResolveFX/OFX effect to a clip
```
apply_ofx_to_clip(regid="com.blackmagicdesign.resolvefx.vignette",
                  params='{"Opacity": 0.8}',
                  track_type="video", track_index=1, item_index=0)
```
- `regid` = the wireId **WITHOUT** the `ofx.` prefix (the tool adds it). Get it from
  `get_resolvefx_registry()`.
- The node is created in the clip's Fusion comp and **spliced before `MediaOut1`**, so it renders.
- `params` is an optional JSON of input→value; enum inputs take the **integer** index.
- Verify with `screenshot`. Good upbeat-look picks: `vignette`, `glow`, `filmlook`,
  `lightray`, `sharpen`, `gaussianblur` (for a rack-focus / blur-in).

## 3 — Insert a title / lower-third / chapter card (incl. MotionVFX)
1. Move the playhead where the card should start: `set_current_timecode("HH:MM:SS:FF")`.
2. Insert by the template's **display name** (from `enumerate_templates`):
```
insert_template_by_name(kind="fusion_title", name="mTuber 4 Chapter")
```
   - `kind`: `fusion_title` for Fusion title packs (MotionVFX), `title` for Resolve's built-in
     Text+/titles, `fusion_generator`/`generator` for generators. The tool retries with the
     internal template-id on a `None` result.
3. Fill the text: `set_title_text(text="Chapter 1 — Setup", track_type="video",
   track_index=<the title's track>, item_index=<its index>)`. (MotionVFX titles expose a
   Text+ node; `set_title_text` finds it. Some packs have several text fields — for those, edit
   in the GUI or drive the Fusion inputs with `fusion_set_input`.)
4. Verify with `get_timeline_items` + `screenshot`.

## 4 — When enumerate can't be trusted (old server build)
Read the real insert names straight from a pack (a `.drfx` is a ZIP):
```
python3 -c "import zipfile,os; z=zipfile.ZipFile(os.path.expanduser('~/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Templates/mTuber4.drfx')); \
print('\n'.join(sorted({p.split('/')[-1][:-8] for p in z.namelist() if p.lower().endswith('.setting') and 'Edit/Titles/' in p and '__MACOSX' not in p})))"
```
The basenames are the names you pass to `insert_template_by_name`.

## Guardrails
- **Match the lane** (table above). Trying to `insert_template_by_name` a Transition/Effect
  returns an error or a no-op — those are GUI-only.
- **`apply_ofx_to_clip` needs a `MediaOut1`** in the clip's comp (there is one by default). If a
  clip has no Fusion comp yet, the splice still works; if it errors, `add_fusion_comp` first.
- **Insert mutates the live timeline** with no scripted undo — confirm placement first; work on a
  duplicate/versioned timeline, not the master.
- Relay `Error:` strings; verify visually with `screenshot`. See the base skill's
  `operating-notes.md` for the `ofx.`-prefix and Fusion gotchas.

## Honest limits
- Titles/generators: scriptable. **Transitions & effects packs: GUI only** (no scripting API).
- `set_title_text` sets the primary Text+ field; multi-field MotionVFX layouts may need GUI or
  `fusion_set_input` per input.
- `enumerate_templates` returns names as registered by the file; a rare pack may register a
  different display name in Resolve — if an insert returns "template not resolved", open the
  Effects Library in the GUI to confirm the exact name.
